# Import libraries
# -------------------------
import pandas as pd
import matplotlib.pyplot as plt
from sklearn.preprocessing import StandardScaler
from sklearn.cluster import KMeans
from scipy.cluster.hierarchy import dendrogram, linkage, fcluster

# -------------------------
# 1. Load Dataset with correct encoding
# -------------------------
df = pd.read_csv("sales_data_sample.csv", encoding='latin1')  # UnicodeDecodeError fix
print("Dataset loaded successfully!")
print(df.head())



# 2. Select numeric columns for clustering
numeric_cols = df.select_dtypes(include=['int64', 'float64']).columns
X = df[numeric_cols]


# 3. Standardize the data
scaler = StandardScaler()
X_scaled = scaler.fit_transform(X)




# 4. Elbow Method to determine optimal K for K-Means
wcss = []
for i in range(1, 11):
    kmeans = KMeans(n_clusters=i, random_state=42)
    kmeans.fit(X_scaled)
    wcss.append(kmeans.inertia_)

plt.figure(figsize=(8,5))
plt.plot(range(1, 11), wcss, marker='o')
plt.title('Elbow Method')
plt.xlabel('Number of clusters')
plt.ylabel('WCSS')
plt.show()





# 5. K-Means Clustering
# -------------------------
k = 4  # choose based on elbow plot
kmeans = KMeans(n_clusters=k, random_state=42)
df['KMeans_Cluster'] = kmeans.fit_predict(X_scaled)
print("\nK-Means Clustering result:")
print(df.head())






# 6. Hierarchical Clustering
linked = linkage(X_scaled, method='ward')

plt.figure(figsize=(10, 7))
dendrogram(linked, orientation='top', distance_sort='descending', show_leaf_counts=True)
plt.title('Hierarchical Clustering Dendrogram')
plt.show()

# Assign clusters (cut dendrogram at k clusters)
df['Hier_Cluster'] = fcluster(linked, k, criterion='maxclust')
print("\nHierarchical Clustering result:")
print(df.head())

## 3. Important difference between the two algorithms

| Divides data into K clusters.               | Creates a tree-like structure of clusters.         |
| Requires the number of clusters in advance. | Does not require the number of clusters initially. |
| Uses cluster centres.                       | Uses distances between data points or clusters.    |
| Uses the Elbow Method to help select K.     | Uses a dendrogram to understand cluster formation. |

### Basic Questions

1\. What is clustering?

Clustering is an unsupervised machine learning technique used to group similar data points together.

2\. What is unsupervised learning?

Unsupervised learning is a type of machine learning in which the model learns from data without predefined labels.

3\. Which algorithms are used in your practical?

K-Means Clustering and Hierarchical Clustering.

4\. Which dataset is used?

The `sales_data_sample.csv` dataset.

5\. What is the aim of this practical?

To group similar sales records into clusters using K-Means and Hierarchical Clustering algorithms.

### K-Means Clustering

6\. What is K-Means clustering?

K-Means is an unsupervised learning algorithm that divides data into K groups based on similarity.

7\. What does K represent?

K represents the number of clusters we want to create.

8\. How does K-Means work?

First, it selects K cluster centres. Then it assigns each data point to the nearest centre and updates the centres. This process continues until the clusters become stable.

9\. What is a centroid?

A centroid is the centre point of a cluster.

10\. Why is K-Means used?

It is used to group similar data points and find patterns in data.

11\. What is the Elbow Method?

The Elbow Method helps us select the suitable number of clusters by plotting WCSS against different K values.

12\. What is WCSS?

WCSS stands for Within-Cluster Sum of Squares. It measures how close data points are to their cluster centres.

13\. Why does WCSS decrease when K increases?

Because more clusters allow data points to be closer to their respective cluster centres.

14\. What is `random_state=42`?

It helps produce repeatable results when the code is executed again.

### Hierarchical Clustering

15\. What is Hierarchical Clustering?

It is an unsupervised learning algorithm that creates clusters in a tree-like structure.

16\. What is a dendrogram?

A dendrogram is a tree-like graph that shows how data points or clusters are joined together.

17\. What are the types of Hierarchical Clustering?

There are two types:

- Agglomerative – Bottom-up approach.
- Divisive – Top-down approach.

18\. Which type is used in your practical?

Your code uses the `linkage()` function to perform agglomerative hierarchical clustering.

19\. What is the Ward method?

Ward's method combines clusters in a way that minimizes the increase in within-cluster variation.

20\. What is the use of `fcluster()`?

It creates cluster labels from the hierarchical clustering results.

### Data Preprocessing

21\. What is StandardScaler?

StandardScaler is used to bring numerical features to a similar scale.

22\. Why is scaling important in clustering?

Clustering uses distance calculations. Scaling prevents features with larger values from dominating the results.

23\. What is Pandas?

Pandas is a Python library used to load and analyse datasets.

24\. What is Matplotlib?

Matplotlib is a Python library used to create graphs and visualizations.

25\. What does `select_dtypes()` do?

It selects columns based on their data types, such as integer and float columns.

### Difference and Advantages

26\. What is the difference between K-Means and Hierarchical Clustering?

| K-Means                | Hierarchical                                                  |
| ---------------------- | ------------------------------------------------------------- |
| Creates K clusters.    | Creates a hierarchy of clusters.                              |
| Uses centroids.        | Uses distances between clusters.                              |
| Uses the Elbow Method. | Uses a dendrogram.                                            |
| Requires K in advance. | Number of clusters can be selected by cutting the dendrogram. |

27\. What are the advantages of K-Means?

- Easy to understand.
- Simple to implement.
- Works well for many clustering problems.

28\. What are the disadvantages of K-Means?

- We must select K.
- Sensitive to outliers.
- Results can depend on initial centroids.

29\. What are the advantages of Hierarchical Clustering?

- Shows clusters in a tree structure.
- Helps understand relationships between clusters.
- Does not require the final number of clusters at the beginning.

30\. What are the disadvantages of Hierarchical Clustering?

- Can be slow for large datasets.
- Sensitive to noise and outliers.
- Once clusters are joined, they are not separated again in agglomerative clustering.
