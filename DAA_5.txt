int deterministicPartition(vector<int>& arr, int low, int high) {

    int pivot = arr[low];
    int i = low;
    int j = high;

    while (i < j) {

        while (i <= high - 1 && arr[i] <= pivot) {
            i++;
        }

        while (j >= low + 1 && arr[j] > pivot) {
            j--;
        }

        if (i < j) {
            swap(arr[i], arr[j]);
        }
    }

    swap(arr[low], arr[j]);

    return j;
}

// Randomized Partition
int randomizedPartition(vector<int>& arr, int low, int high) {

    int randomIndex = low + rand() % (high - low + 1);

    swap(arr[low], arr[randomIndex]);

    return deterministicPartition(arr, low, high);
}

                     bool isRandomized) {

            pIndex = deterministicPartition(arr, low, high);

## 2. Explanation of code – What and why?

### A. Header files

```
#include <bits/stdc++.h>
using namespace std;
```

- `bits/stdc++.h` includes the required C++ libraries.
- `using namespace std` allows us to use `cin`, `cout` and `vector` directly.

### B. Deterministic partition

```
int deterministicPartition(vector<int>& arr, int low, int high)
```

Why? To divide the array using a fixed pivot.

```
int pivot = arr[low];
```

Selects the first element as the pivot.

```
int i = low;
int j = high;
```

Creates two pointers. `i` moves from left to right and `j` moves from right to left.

```
while (i < j)
```

Repeats until both pointers meet or cross.

```
while (i <= high - 1 && arr[i] <= pivot)
    i++;
```

Moves the left pointer forward while elements are smaller than or equal to the pivot.

```
while (j >= low + 1 && arr[j] > pivot)
    j--;
```

Moves the right pointer backward while elements are greater than the pivot.

```
if (i < j)
    swap(arr[i], arr[j]);
```

Swaps elements that are on the wrong sides of the pivot.

```
swap(arr[low], arr[j]);
return j;
```

Places the pivot in its correct position and returns its index.

### C. Randomized partition

```
int randomizedPartition(vector<int>& arr, int low, int high)
```

Why? To select a random pivot instead of always selecting the first element.

```
int randomIndex = low + rand() % (high - low + 1);
```

Generates a random index between `low` and `high`.

```
swap(arr[low], arr[randomIndex]);
```

Moves the randomly selected element to the first position.

```
return deterministicPartition(arr, low, high);
```

Uses the same partition function to arrange elements around the new pivot.

### D. Quick Sort helper

```
void quickSortHelper(vector<int>& arr, int low, int high,
                     bool isRandomized)
```

Why? To sort the array recursively using the selected method.

```
if (low < high)
```

Checks whether at least two elements are present in the current part.

```
if (isRandomized)
    pIndex = randomizedPartition(arr, low, high);
else
    pIndex = deterministicPartition(arr, low, high);
```

Selects the partition method.

```
quickSortHelper(arr, low, pIndex - 1, isRandomized);
quickSortHelper(arr, pIndex + 1, high, isRandomized);
```

Sorts the left and right parts separately.

### E. Quick Sort function

```
vector<int> quickSort(vector<int> arr, bool isRandomized)
```

Why? To start sorting and return the sorted array.

```
quickSortHelper(arr, 0, arr.size() - 1, isRandomized);
return arr;
```

Starts sorting from the first index to the last index and returns the sorted array.

### F. Display function

```

```

Why? To display the array elements.

```

```

Prints every element one by one.

## 4. Difference between both methods

| Deterministic Quick Sort                     | Randomized Quick Sort                             |
| -------------------------------------------- | ------------------------------------------------- |
| Selects the first element as pivot.          | Selects a random element as pivot.                |
| Uses a fixed selection rule.                 | Uses random selection.                            |
| Can give poor performance on certain inputs. | Reduces the chance of repeatedly poor partitions. |
| Average: O(n log n)                          | Expected: O(n log n)                              |

## 5. Viva questions and answers

Q1. What is Quick Sort?

Quick Sort is a sorting algorithm that uses the Divide and Conquer technique.

Q2. What is a pivot?

A pivot is an element used to divide the array into two parts.

Q3. What is deterministic Quick Sort?

It selects the pivot using a fixed rule. In our program, it selects the first element.

Q4. What is randomized Quick Sort?

It selects the pivot randomly from the array.

Q5. Why do we use randomization?

To reduce the chance of getting unbalanced partitions repeatedly.

Q6. What is partitioning?

It is the process of arranging smaller elements before the pivot and larger elements after it.

Q7. What is recursion?

A function calling itself is called recursion.

Q8. Why do we use swap()?

To exchange two elements.

Q9. Why do we use rand()?

To generate a random number.

Q10. Why do we use srand(time(0))?

To initialize random number generation using the current time.

Q11. What is the average time complexity?

O(n log n).

Q12. What is the worst-case time complexity?

O(n²).

Q13. What is the space complexity?

O(log n) on average for the recursion stack, and O(n) in the worst case.

Deterministic Quick Sort

Randomized Quick Sort

Partition

Recursion

Swap

Exchanges elements.
