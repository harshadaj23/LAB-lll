#include <iostream>
#include <vector>
#include <iomanip>

using namespace std;

void printTable(const vector<vector<int>>& dp, int n, int W) {
    cout << "\nDP Table:\n";
    for (int i = 0; i <= n; i++) {
        for (int w = 0; w <= W; w++) {
            cout << setw(5) << dp[i][w];
        }
        cout << endl;
    }
}


int knapsackDP(const vector<int>& weights, const vector<int>& values, int W, vector<int>& selectedItems) {
    int n = weights.size();
    vector<vector<int>> dp(n + 1, vector<int>(W + 1, 0));

    
    for (int i = 1; i <= n; i++) {
        for (int w = 1; w <= W; w++) {
            if (weights[i - 1] <= w) {
                dp[i][w] = max(dp[i - 1][w], dp[i - 1][w - weights[i - 1]] + values[i - 1]);
            } else {
                dp[i][w] = dp[i - 1][w];
            }
        }
    }

    
    printTable(dp, n, W);

    
    int maxProfit = dp[n][W];
    int w = W;
    for (int i = n; i > 0 && maxProfit > 0; i--) {
        if (maxProfit != dp[i - 1][w]) {  // Item i-1 was included
            selectedItems.push_back(i);    // Save the index (1-based) of selected item
            maxProfit -= values[i - 1];
            w -= weights[i - 1];
        }
    }

    return dp[n][W];
}

        } else if (choice != 2) {

        }

}

## 1. Explanation in simple language (Paragraph)

The program solves the 0/1 Knapsack problem using Dynamic Programming. First, it accepts the number of items, their weights, values and maximum bag capacity. It creates a DP table to store the maximum profit for different items and capacities. If an item fits in the bag, the program checks two choices: include the item or exclude the item. It selects the choice that gives maximum profit. After completing the table, it finds the maximum profit and identifies which items are included in the bag. Finally, it displays the DP table, maximum profit and selected items.

## 2. Important functions

- printTable(): Displays the DP table.
- knapsackDP(): Calculates the maximum profit using Dynamic Programming.
- main(): Accepts input, displays the menu and prints the result.

## 10. Important viva questions

Q1. What is the 0/1 Knapsack problem?

It is a problem in which we select items to get maximum profit without exceeding the bag capacity. Each item can be selected only once.

Q2. Why is it called 0/1 Knapsack?

Because an item is either selected (1) or not selected (0).

Q3. Which technique is used?

Dynamic Programming.

Q4. What is a DP table?

It stores the maximum profit for different items and capacities.

Q5. What is backtracking?

It is the process of moving backwards through the DP table to find the selected items.

Q6. What is the time complexity?

\\(O(n \times W)\\), where `n` is the number of items and `W` is the capacity.

Q7. What is the space complexity?

\\(O(n \times W)\\), because we create a two-dimensional DP table.

Remember these three important things for your practical:

1. `dp` table – Stores maximum profits.
2. `max()` – Chooses whether to include or exclude an item.
3. Backtracking – Finds the selected items.
