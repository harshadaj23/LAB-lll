// SPDX-License-Identifier: MIT
pragma solidity ^0.8.20;

contract BankAccount {
    mapping(address => uint256) private balances;

    event Deposit(address indexed account, uint256 amount);
    event Withdraw(address indexed account, uint256 amount);

    function deposit() public payable {
        require(msg.value > 0, "Deposit amount must be greater than 0");
        balances[msg.sender] += msg.value;
        emit Deposit(msg.sender, msg.value);
    }

    function withdraw(uint256 amount) public {
        require(amount > 0, "Withdraw amount must be greater than 0");
        require(balances[msg.sender] >= amount, "Insufficient balance");

        balances[msg.sender] -= amount;
        payable(msg.sender).transfer(amount);

        emit Withdraw(msg.sender, amount);
    }

    function getBalance() public view returns (uint256) {
        return balances[msg.sender];
    }
}

# 1. Complete code explanation

## Line 1: SPDX License

```
// SPDX-License-Identifier: MIT
```

- It specifies the license of the smart contract.
- MIT is an open-source license.
- It tells others how the code can be used.

## Line 2: Solidity version

```
pragma solidity ^0.8.20;
```

- It specifies the Solidity compiler version.
- `^0.8.20` means compiler version 0.8.20 or compatible newer versions below 0.9.0.

## Line 3: Contract declaration

```
contract BankAccount {
```

- `contract` is a keyword used to create a smart contract.
- `BankAccount` is the name of our contract.
- It contains all the banking operations.

## Line 4: Mapping

```
mapping(address => uint256) private balances;
```

This is one of the most important lines.

- Mapping stores data in key-value pairs.
- `address` represents the customer's wallet address.
- `uint256` represents the customer's balance.
- `private` means the mapping cannot be directly accessed by other contracts through its generated getter.

Example:

| Customer address | Balance |
| ---------------- | ------- |
| Customer A       | 3 ETH   |
| Customer B       | 2 ETH   |
| Customer C       | 5 ETH   |

Each customer has a separate balance.

## Line 5–6: Events

```
event Deposit(address indexed account, uint256 amount);
event Withdraw(address indexed account, uint256 amount);
```

- Events record important activities.
- `Deposit` records when money is deposited.
- `Withdraw` records when money is withdrawn.
- `indexed` makes the account address searchable in event logs.

## 2. Deposit function

```
function deposit() public payable {
    require(msg.value > 0, "Deposit amount must be greater than 0");
    balances[msg.sender] += msg.value;
    emit Deposit(msg.sender, msg.value);
}
```

Let's understand each line:

1\. `function deposit()`

Creates a function named deposit.

2\. `public`

Anyone can call this function.

3\. `payable`

Allows the function to receive Ether.

4\. `require(msg.value > 0, ...)`

Checks that the deposited amount is greater than zero.

5\. `msg.value`

Represents the amount of Ether sent with the transaction, measured in wei.

6\. `balances[msg.sender] += msg.value`

Adds the deposited amount to the customer's existing balance.

7\. `emit Deposit(...)`

Records the deposit event.

Example: Deposit 3 ETH

New balance

## 3. Withdraw function

```
function withdraw(uint256 amount) public {
    require(amount > 0, "Withdraw amount must be greater than 0");
    require(balances[msg.sender] >= amount, "Insufficient balance");

    balances[msg.sender] -= amount;
    payable(msg.sender).transfer(amount);

    emit Withdraw(msg.sender, amount);
}
```

Explanation:

1. `withdraw(uint256 amount)` – creates a withdrawal function that accepts an amount.
2. `require(amount > 0)` – checks that the withdrawal amount is greater than zero.
3. `require(balances[msg.sender] >= amount)` – checks whether the customer has sufficient balance.
4. `balances[msg.sender] -= amount` – subtracts the withdrawal amount from the customer's balance.
5. `payable(msg.sender).transfer(amount)` – sends Ether to the customer's wallet.
6. `emit Withdraw(...)` – records the withdrawal event.

Example:

| Details           | Amount  |
| ----------------- | ------- |
| Previous balance  | 3 ETH   |
| Withdrawal        | 0.2 ETH |
| Remaining balance | 2.8 ETH |

Why do we use `payable(msg.sender)`?

Because we need to send Ether to the customer's wallet address.

Why do we use `transfer()`?

It transfers Ether from the contract to the customer's address.

## 4. Get Balance function

```
function getBalance() public view returns (uint256) {
    return balances[msg.sender];
}
```

Explanation:

- `getBalance()` – function used to check the customer's balance.
- `public` – anyone can call it.
- `view` – reads data without changing the blockchain state.
- `returns(uint256)` – returns the balance as an unsigned integer.
- `return balances[msg.sender]` – displays the balance of the customer who called the function.

For example, if the customer's balance is 2.8 ETH, the function returns:

`2800000000000000000` wei.
