## Cell 14: Creating the Neural Network

Most important cell for your practical

```
from tensorflow.keras import Sequentialfrom tensorflow.keras.layers import Densemodel = Sequential()model.add(Dense(7, activation='relu'))model.add(Dense(10, activation='relu'))model.add(Dense(1, activation='sigmoid'))
```

Let's understand each line.

1\. `Sequential()`

Creates a neural network in which data passes through layers one after another.

2\. `Dense(7, activation='relu')`

Creates the first layer with 7 neurons.

- Dense means every neuron is connected to the neurons in the previous layer.
- ReLU is an activation function that helps the network learn patterns.

3\. `Dense(10, activation='relu')`

Creates the second layer with 10 neurons. It learns more patterns from the previous layer.

4\. `Dense(1, activation='sigmoid')`

Creates the output layer with one neuron.

Sigmoid gives an output between 0 and 1, which can be treated as the probability that a customer will leave.

For example:

- Output 0.85 → likely to leave.
- Output 0.20 → likely to stay.

The usual classification threshold is 0.5.
