
#include <bits/stdc++.h>
using namespace std;

// Recursive function
int fibRec(int n)
{
    if(n < 0)
        return -1;

    if(n == 0 || n == 1)
        return n;

    return fibRec(n-1) + fibRec(n-2);
}

// Iterative function
int fibIter(int n)
{
    if(n < 0)
        return -1;

    if(n == 0 || n == 1)
        return n;

    int a = 0, b = 1, c;

    for(int i = 2; i <= n; i++)
    {
        c = a + b;
        a = b;
        b = c;
    }

    return b;
}

// Function to print Fibonacci series
void printFibSeries(int n)
{
    if(n < 0)
    {
        cout << "Enter a positive number" << endl;
        return;
    }

    if(n == 0)
    {
        cout << "No terms to print" << endl;
        return;
    }

    int a = 0, b = 1, c;

    cout << "Fibonacci Series: ";

    for(int i = 0; i < n; i++)
    {
        if(i == 0)
            cout << a << " ";
        else if(i == 1)
            cout << b << " ";
        else
        {
            c = a + b;
            cout << c << " ";
            a = b;
            b = c;
        }
    }

    cout << endl;
}

// Main function
int main()
{
    while(true)
    {
        cout << "\n----- FIBONACCI MENU -----" << endl;
        cout << "1. Fibonacci using Recursion" << endl;
        cout << "2. Fibonacci using Iteration" << endl;
        cout << "3. Print Fibonacci Series" << endl;
        cout << "4. Exit" << endl;

        int op;
        cout << "Enter option: ";
        cin >> op;

        if(op == 1)
        {
            int n;
            cout << "Enter the value of n: ";
            cin >> n;

            int res = fibRec(n);

            if(res == -1)
                cout << "Enter a non-negative number" << endl;
            else
                cout << "Result is: " << res << endl;
        }

        else if(op == 2)
        {
            int n;
            cout << "Enter the value of n: ";
            cin >> n;

            int res = fibIter(n);

            if(res == -1)
                cout << "Enter a non-negative number" << endl;
            else
                cout << "Result is: " << res << endl;
        }

        else if(op == 3)
        {
            int n;
            cout << "Enter the number of terms: ";
            cin >> n;

            printFibSeries(n);
        }

        else if(op == 4)
        {
            cout << "Exiting program..." << endl;
            break;
        }

        else
        {
            cout << "Invalid option!" << endl;
        }
    }

    return 0;
}

















The Fibonacci program is used to generate the Fibonacci series using recursion and iteration. In this series, each number is the sum of the previous two numbers, starting from 0 and 1.

The program contains three functions. The fibRec() function calculates Fibonacci numbers using recursion, where a function calls itself. The fibIter() function calculates Fibonacci numbers using a for loop. The printFibSeries() function prints the complete Fibonacci series for the given number of terms.

The main() function displays a menu where the user can select recursion, iteration, print the series, or exit the program. If the user enters a negative number, the program displays an error message.

Example: If the number of terms is 7, the output is `0 1 1 2 3 5 8`.

Conclusion: Thus, we successfully implemented the Fibonacci series using recursion and iteration in C++.







# Fibonacci Series – Simple Explanation

### 1. Aim

To implement Fibonacci Series using Recursion and Iteration in C++.

### 2. What is Fibonacci Series?

In Fibonacci Series, every next number is the sum of the previous two numbers.

Example: `0, 1, 1, 2, 3, 5, 8, 13...`

### 3. Explanation of Program

1\. Header File

```
#include <bits/stdc++.h>
using namespace std;
```

Used to include standard C++ libraries.

2\. Recursive Function

```
int fibRec(int n)
```

- Calculates Fibonacci using function calling itself.
- If n is 0 or 1, it returns n.
- Otherwise, it adds `fibRec(n-1) + fibRec(n-2)`.

3\. Iterative Function

```
int fibIter(int n)
```

- Calculates Fibonacci using a `for` loop.
- `a = 0` and `b = 1` are the first two numbers.
- `c = a + b` calculates the next number.
- The loop repeats until the required number is calculated.

4\. Print Fibonacci Series

```
void printFibSeries(int n)
```

Prints the complete Fibonacci series for the given number of terms.

5\. Main Function

```
int main()
```

Displays the menu and allows the user to select:

1. Fibonacci using Recursion.
2. Fibonacci using Iteration.
3. Print Fibonacci Series.
4. Exit.
